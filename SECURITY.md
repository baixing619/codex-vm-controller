# Security boundary

One installation binds one local Hyper-V VM, owner SID and host. Changing that policy is an installation action, not an HTTP action. Keep the policy and discovery directory private to the owner, SYSTEM and Administrators. Do not publish its contents.

Loopback HTTP uses an unpredictable runtime token and exact Host/Origin validation. It must never be port-forwarded or exposed on the LAN. Same-user processes and administrators are outside this credential isolation boundary.

A capture is an observation, not permission to enter input. Input is bound to a viewed frame and must still be authorized by the human. A native receipt is not a verified guest UI effect. Unknown cancellation drain must not cause retries.

The native owner is non-elevated. Windows UAC is retained for the device worker, which verifies its parent pipe, policy digest and fixed VM. Never disable these checks or change host/user/VM checks to make a failed connection pass.

Do not attach live policy, discovery, screen frames, debug rows, credentials, host identity or private VM data to public issues. Runtime debug is bounded memory only.
